# CHRONOS Phase 06 — Time Morph Visual References

Extract this ZIP into the CHRONOS-AETERNUM repository root.
Files will land under `public/chronos/phase06/`.

These images are **visual references only**. They are not final textures, not 3D meshes, and not a substitute for procedural / reusable Three.js geometry.

## Phase 06 goal
- Transform the same Aeternum geography across five eras.
- Keep camera position stable while the local world morphs through time.
- Extend Phase 05 from discrete era swapping into continuous, reversible time morphing.
- Evolve all five districts: Chronos Plaza, Old District, River Crossing, Industrial Quarter, Observatory.
- Keep performance under control using reusable geometry, layered variants, and deterministic transition logic.
