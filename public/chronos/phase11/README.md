# CHRONOS Phase 11 — Mobile & Performance Optimization

Extract ZIP at repository root. Files land in `public/chronos/phase11/`.

Images are art direction and responsive layout references, NOT actual benchmark screenshots. The FPS/load/memory figures on the artwork are illustrative; measure the actual application before claiming improvements.

Audio files are re-encoded Phase 10 concept WAV files (Ogg Opus 24kHz mono, 40 kbps). These are bandwidth-oriented alternatives, not new sound designs. Preserve original Phase 10 audio as fallback if necessary. Do not play duplicate sources. Verify browser codec support and compare perceptual quality.

Primary scope: stable experience across mobile/tablet/desktop, appropriate quality preset, reduced GPU cost, interaction robustness, asset loading, accessibility and truthful performance reporting.

Minimum controls: quality Auto/High/Medium/Low; user override; reduced-motion; mobile touch controls; readable timeline and final choices; error and loading states.

This is Phase 11, not Phase 12: do not restructure the whole project or deploy the final release. Use Vercel preview build verification if configured.
