# CHRONOS — Phase 03 Aeternum visual asset pack

The images are **original concept-art references**, cropped from the cohesive Phase 03 art-direction board. They are not finished production-ready 3D textures, mesh files, accurate architectural blueprints, or connected panoramic skyboxes. Some panel captions or inset views may remain within the crops.

Copy the `public` folder into the existing Next.js project root. The resulting paths are:

- `/chronos/phase03/00-full-art-direction-board.png` — master visual direction
- `/chronos/phase03/01-city-panorama.png` — city-wide aerial mood / 2026 palette
- `/chronos/phase03/02-world-map.png` — approximate district adjacency only; not a scale-accurate map
- `/chronos/phase03/03-chronos-plaza.png` — clock tower and central square
- `/chronos/phase03/04-old-district.png` — historic neighborhoods
- `/chronos/phase03/05-river-crossing.png` — river and bridges
- `/chronos/phase03/06-industrial-quarter.png` — industrial identity
- `/chronos/phase03/07-observatory.png` — hilltop dome

The camera-ready scene must use actual React Three Fiber / Three.js geometry; do not apply these images as fake full-screen scenes.
The previously approved story era dates are 1200 BCE, 1450, 1890, 2026, and 2200. Phase 03 builds ONLY the year 2026.
All images were created for the CHRONOS concept in this conversation.
