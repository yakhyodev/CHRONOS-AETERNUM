# CHRONOS — Phase 04 | Real photographic references

These photographs are from **Wikimedia Commons** (not AI-generated). They are intended as **art-direction / camera / architecture references**, NOT as one coherent fictional-world texture or fake 3D set. Attribution and license obligations apply if distributing photographs or derived images.

## How to download (Windows PowerShell)

1. Unzip this archive into a temporary directory or the project root.
2. Right-click `download_images.ps1` and choose Run with PowerShell, or run it in PowerShell:
   `powershell -ExecutionPolicy Bypass -File .\download_images.ps1`
3. It downloads images into `public/chronos/phase04/references/` under the extracted folder.
4. Copy `public/chronos/phase04/references/` into your Chronos project, then commit/push if you wish to maintain the references in GitHub. Don't delete license information.

If Wikimedia refuses automated download, visit the linked Commons file pages and download the image manually.
